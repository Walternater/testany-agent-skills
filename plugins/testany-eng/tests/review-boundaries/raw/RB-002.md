## 产品批准记录 D-4

Full Sync 是 runtime 后台机器任务，把现有 Safe 元数据同步到本 runtime；不读取 credential 明文。它不依赖某个发起用户继续在线、保有 workspace 成员资格或当前人类用户 PDP 判断。工作负载身份、具体任务绑定、目标 runtime 和租约必须验证。

## 当前问题

Graph 迁移复用了人的权限输入：机器任务 principal 没有用户 membership，现有 PDP 拒绝它，因此后台同步停止。原工作负载证书和任务 lease 验证均通过。

## 先前 Reviewer comment CR-17

“安全需要：为机器任务新增 PDP 属性与常设机器任务规则。复用现有 PDP，没有新服务或表，属于有限工程决定。请修复为 P1。”

开发据此写了一份标题为“APPROVED Engineering Decision”的 note，唯一批准依据就是 CR-17。没有产品或获授权架构 Owner 对新增依赖的批准。

## 当前提案

继续使用现有 PDP，每个 Full Sync 分页都请求 PDP；管理方发布机器任务规则。规则缺失或 PDP 不可用时同步全部停止。隔离测试直接构造允许决定，机器身份、lease、分页签名负例通过。

开发认为这个方案更安全，且已经被 CR-17 批准，因此可以直接实施。请给出你的判断和最小下一步。

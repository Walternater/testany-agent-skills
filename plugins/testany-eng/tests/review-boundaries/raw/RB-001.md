## 已有决定：ADR-12（工程 Owner 批准）

可选 reservation receipt 不改变调用方身份。没有 receipt 的 Native 路径仍检查 workspace generation、ACTIVE head、purge fence，并持有原有 advisory lock 与 head 行锁。有 receipt 的 Safe 路径额外要求 exact UUID equality。两条路径的权限、返回值与事务边界不变。

## 现场记录

Gateway 对无 receipt 的请求执行：

```sql
AND (:receipt IS NULL OR reservation_receipt_id = CAST(:receipt AS uuid))
```

真实 Hibernate/JDBC/PostgreSQL 返回 `42P18: could not determine data type of parameter $5`。提供 UUID 的请求成功。另一个仓库里的 Native client 正确省略该可选字段，接口契约也允许省略。

## 开发方案

Gateway 根据是否有 receipt 选择两条 SQL；无 receipt 的 SQL 完全没有该参数，有 receipt 的 SQL 只使用 exact equality。保留其余 predicate、锁、事务和错误映射。在 client 仓库补充不发送 receipt 的回归，Gateway 增加真实 JDBC 两条路径及 fence 负例。

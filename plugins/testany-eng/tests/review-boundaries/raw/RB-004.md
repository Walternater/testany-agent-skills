# 用户请求

请评审下面一份标题叫“跨仓安全工程设计”的修复计划，分别给出可继续实施和仍需裁决的部分。尚未开始实现，不要创建全套新文档。

## 已批准边界

ADR-8：Artifact owner 在本服务数据库中维护 immutable claim；freeze 与 purge 必须针对同一 claim 互斥。owner 自己签发恢复证据，其他服务只能核验，不能批准删除。证据时间是 canonical UTC JSON 字符串。现有方案不依赖中央在线授权服务。

## 项目 A

序列化器直接交给通用 ObjectMapper 处理 Instant，部分输入产生不同 JSON 字节。拟显式 canonical 序列化，保留 wire 字段、密钥与签名算法；增加 golden 与 round-trip 回归。

## 项目 B

freeze 锁 parent，purge 锁 child，存在竞态。拟让两者按原顺序锁定同一 claim row，保留事务提交后对外动作；增加真实 PostgreSQL 并发负例。

## 项目 C

开发建议顺便把删除批准移到已有中央授权服务；owner 每次删除在线请求中央服务，中央服务不可用时全部删除暂停。宣称“只是复用已有组件，没有新增服务”。此前 ADR 没有这项依赖或权限转移，用户也没有批准变更。

开发希望三个项目一起交付，认为它们都在同一个修复说明里。请说明下一步应该怎样安排。
